## Systems programmer, moving into security

I'm a systems-focused software engineer from Morocco, specializing in **C**, **C++**, and
network infrastructure. My work starts from the fundamentals: I build to the **C++98**
standard, keep my code in **Orthodox Canonical Form**, and hold memory safety and
architecture before features.

I've spent my time in low-level programming and containerized environments, and I'm now
translating that foundation into **cybersecurity** — using my understanding of system
architecture to find vulnerabilities and to build software that stays secure and resilient
under real conditions.

## What I focus on

- **Systems & infrastructure work** in C and C++, from the ground up.
- **Network security** — monitoring, capture, and traffic analysis on external wireless
  adapters in monitor mode and packet-injection scenarios, to understand how systems
  actually fail.
- **Containerized development** for reproducible, isolated environments.
